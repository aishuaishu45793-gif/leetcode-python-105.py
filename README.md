## ▶️ How to Run the Programs

### Step 1: Clone a Repository

Open your terminal and run:

```bash
git clone https://github.com/aishuaishu45793-gif/leetcode-python-96.py.git
```

Replace the repository URL with the project you want to practice.

### Step 2: Open the Project

Open the downloaded project folder in Visual Studio Code.

### Step 3: Run a Python File

Open the Python file in the editor and run:

```bash
python filename.py
```

Replace `filename.py` with the actual name of your Python file.

On Windows, you can also try:

```bash
py filename.py
```

### Step 4: Check the Output

View the output in the VS Code terminal and modify the input values to experiment with different cases.
